1

La sentència SELECT · àlies · concatenació · DISTINCT

Criteri 3.1 · 3.2 — Recuperació bàsica de dades

La sentència SELECT és la base de tot SQL. Permet triar quines columnes mostrar (projecció), de quina taula i, opcionalment, renomenar les capçaleres amb àlies.

Sintaxi bàsica
SELECT * | {[DISTINCT] columna | expressió [àlies], ...}
FROM taula;

SELECT indica les columnes a mostrar. FROM identifica la taula. * selecciona totes les columnes. DISTINCT elimina duplicats.
Exemples — SELECT bàsic i DISTINCT
Exemple 1 · Totes les columnes / columnes concretes
Explicació
SELECT * retorna totes les columnes. En producció, és preferible llistar només les columnes necessàries. Les sentències SQL no distingeixen majúscules/minúscules i es poden escriure en diverses línies.
Exemple 2 · Àlies de columna
Explicació
L'àlies canvia la capçalera del resultat. Amb AS o sense. Si l'àlies conté espais o caràcters especials, cal posar-lo entre cometes dobles: "Hire Date".
Exemple 3 · Operador de concatenació ||
Explicació
L'operador || uneix cadenes de text. Els literals de text van entre cometes simples. El resultat és una sola columna amb l'àlies indicat.
Exemple 4 · Expressions aritmètiques i DISTINCT
Explicació
DISTINCT elimina les files duplicades del resultat. Les expressions aritmètiques (*, /, +, -) es poden usar al SELECT. L'ordre de prioritat és el matemàtic estàndard; useu parèntesis per controlar-lo.

2

Filtratge amb WHERE i ordenació amb ORDER BY

Criteri 3.2 — Restricció i ordenació de files

La clàusula WHERE filtra les files que compleixen una condició. ORDER BY ordena el resultat. S'executen en aquest ordre: FROM → WHERE → SELECT → ORDER BY.

Operadors de comparació i lògics
OperadorDescripcióExemple
= != <>Igualtat / diferènciaWHERE salary = 5000
< > <= >=Comparació numèricaWHERE salary > 12000
BETWEEN a AND bRang inclusiuWHERE salary BETWEEN 5000 AND 12000
IN (v1, v2, ...)Pertany a una llistaWHERE department_id IN (20, 50)
LIKE 'patró'Coincidència de patró (% = 0 o més caràcters; _ = exactament 1)WHERE last_name LIKE 'S%'
IS NULL / IS NOT NULLValor nul / no nulWHERE commission_pct IS NULL
AND OR NOTOperadors lògicsWHERE salary > 5000 AND dept_id = 80
Exemples
Exemple 5 · WHERE amb operadors comparatius i lògics
Explicació
La clàusula WHERE filtra les files abans de mostrar el resultat. Els operadors de comparació (=, !=, <, >) s'usen amb números i dates. Les cadenes de text van sempre entre cometes simples i distingeixen majúscules/minúscules. AND requereix que totes les condicions siguin certes; OR n'és suficient amb una.
Exemple 6 · BETWEEN, IN, LIKE i IS NULL
Explicació
BETWEEN a AND b és inclusiu als dos extrems (equivalent a >= a AND <= b). IN (v1, v2, ...) comprova si el valor pertany a la llista (equivalent a múltiples OR). LIKE usa comodins: % substitueix zero o més caràcters, _ substitueix exactament un caràcter. Mai s'usa = NULL: sempre IS NULL o IS NOT NULL.
Exemple 7 · ORDER BY (ASC / DESC / per posició)
Explicació
ORDER BY accepta el nom de la columna, l'àlies o la seva posició numèrica al SELECT. Per defecte ordena ascendent (ASC). Es poden ordenar per diverses columnes separades per comes.

Funcions d'una sola fila

Criteri 3.2 — Caràcter, numèriques i de data

Les funcions d'una sola fila operen sobre cada fila individualment i retornen un resultat per fila. Es divideixen en funcions de caràcter, numèriques i de data.

Funcions de caràcter principals
FuncióDescripcióExemple
UPPER(s)Converteix a majúsculesUPPER('hola') → 'HOLA'
LOWER(s)Converteix a minúsculesLOWER('HOLA') → 'hola'
INITCAP(s)Primera lletra de cada paraula en majúsculaINITCAP('joan mas') → 'Joan Mas'
LENGTH(s)Longitud de la cadenaLENGTH('hola') → 4
SUBSTR(s,i,n)Subcadena des de la posició i, n caràctersSUBSTR('Oracle',1,3) → 'Ora'
INSTR(s,sub)Posició de la primera ocurrència de subINSTR('Oracle','a') → 3
LPAD(s,n,c)Omple per l'esquerra fins a longitud n amb el caràcter cLPAD(5000,10,'$') → '$$$$$5000'
RPAD(s,n,c)Omple per la dreta fins a longitud nRPAD('ABC',6,'*') → 'ABC***'
TRIM(s)Elimina espais dels dos extremsTRIM(' hola ') → 'hola'
Funcions numèriques
FuncióDescripcióExemple
ROUND(n,d)Arrodoneix n a d decimalsROUND(45.926,2) → 45.93
TRUNC(n,d)Trunca n a d decimals (sense arrodonir)TRUNC(45.926,2) → 45.92
MOD(n,m)Residu de n/mMOD(1600,300) → 100
Funcions de data
FuncióDescripcióExemple
SYSDATEData i hora actuals del servidorSELECT SYSDATE FROM dual
MONTHS_BETWEEN(d1,d2)Nombre de mesos entre dues datesMONTHS_BETWEEN(SYSDATE, hire_date)
ADD_MONTHS(d,n)Afegeix n mesos a una dataADD_MONTHS(hire_date, 6)
NEXT_DAY(d,dia)Primer dia de la setmana indicat, posterior a dNEXT_DAY(hire_date,'MONDAY')
LAST_DAY(d)Últim dia del mes de dLAST_DAY(SYSDATE)
ROUND(d,'MONTH')Arrodoneix la data al mes o any més properROUND(SYSDATE,'YEAR')
TRUNC(d,'MONTH')Trunca la data al primer dia del mes o anyTRUNC(hire_date,'YEAR')
Exemple 8 · Funcions de caràcter
Explicació
INITCAP posa majúscula a la primera lletra de cada paraula. LENGTH retorna el nombre de caràcters. SUBSTR(cad, inici, longitud) extreu una subcadena: la posició comença a 1. Usar UPPER al WHERE garanteix que la comparació funcioni independentment de com estan emmagatzemades les dades.
Exemple 9 · Funcions numèriques i de data
Explicació
ROUND(n, d) arrodoneix a d decimals; TRUNC(n, d) trunca sense arrodonir. MOD(n, m) retorna el residu de la divisió. SYSDATE és la data i hora actuals del servidor. La resta de dues dates a Oracle retorna el nombre de dies; dividint per 7 s'obtenen setmanes. MONTHS_BETWEEN calcula mesos entre dues dates.

Funcions de conversió i expressions condicionals

Criteri 3.2 — TO_CHAR, TO_DATE, NVL, CASE, DECODE

Les funcions de conversió transformen valors d'un tipus de dada a un altre. Les expressions condicionals permeten retornar valors diferents en funció d'una condició, sense necessitat d'instruccions de control de flux.

Funcions de conversió
FuncióDescripcióExemple
TO_CHAR(d,'format')Data → text amb formatTO_CHAR(hire_date,'DD/MM/YYYY')
TO_CHAR(n,'format')Número → text amb formatTO_CHAR(salary,'$99,999.00')
TO_DATE(s,'format')Text → dataTO_DATE('01/01/2024','DD/MM/YYYY')
TO_NUMBER(s)Text → númeroTO_NUMBER('1234')
Formats de data freqüents (TO_CHAR)
DD dia · MM mes numèric · MON mes abreujat · MONTH mes complet · YYYY any 4 dígits · DAY nom del dia · HH24:MI:SS hora · El prefix fm elimina els espais en blanc.
Funcions de control de valors nuls i condicionals
FuncióDescripcióExemple
NVL(expr, subst)Substitueix NULL per substNVL(commission_pct, 0)
NVL2(expr, si_no_null, si_null)Retorna valors diferent si és o no NULLNVL2(commission_pct, 'Sí', 'No')
NULLIF(a, b)Retorna NULL si a=b, o a si a≠bNULLIF(LENGTH(first_name), LENGTH(last_name))
COALESCE(v1, v2, ...)Primer valor no NULL de la llistaCOALESCE(commission_pct, 0)
DECODE(expr, v1,r1, v2,r2, ..., def)Equivalent a CASE-WHEN simplificatDECODE(job_id,'IT_PROG','C','SA_REP','D','0')
Exemple 9 · TO_CHAR, NVL i expressió CASE
Explicació
CASE WHEN ... THEN ... ELSE ... END és l'expressió condicional estàndard SQL. DECODE és la versió Oracle equivalent però menys portable. Ambdues retornen un valor diferent per a cada condició.
